local AI budget panel. Multi-project dashboards, annotations and an owner decision
center are not implemented. Specification approval updates requirements only.

creation-only workflow/child maps, independent layout overlays and paginated
overviews with full matching totals. Opt-in management summaries list only
explicitly registered choices. Candidate paths remain private pending metadata;
registration does not discover projects or import source. All project data and
candidate paths belong outside public source.

access boundaries. Grant changes over HTTP return 503 until real local action
sessions exist. Only the fixed synthetic calculator can reach legacy task actions;
native coding and HTTP source import remain blocked. Shared annotation/evidence/
decision contracts are foundations for later controllers, not working UI features.

implementation and their own verification. Registry metadata never supplies
